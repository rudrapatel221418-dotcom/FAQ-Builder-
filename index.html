System Implementation & Architecture Details

This system was designed and implemented using modern client-server architecture principles:

Backend Framework

FastAPI (Python) with CORS middleware, asynchronous route handling, and multipart file upload processing.

NLP & AI Reasoning

Groq API using deep language models for high-speed prompt execution and question generation.

Document Parser Engine

Integrated pypdf for PDF stream reading, python-docx for Microsoft Word, and standard UTF-8 stream readers.

Frontend Architecture

Responsive Single-Page Application (SPA) built with Semantic HTML5, CSS3 Variables, and Vanilla ES6+ JavaScript.
